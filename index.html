📖 How the 836 FTL v2 Works

What is it?

The 836 FTL v2 is a Minecraft ender pearl cannon that uses TNT to fire a pearl thousands of blocks in a single shot. In the Nether, distances are 8× compressed, so 1,000 nether blocks = 8,000 overworld blocks of travel.

Pearl Physics (every tick = 1/20 second)

motion.y -= 0.03 // gravity motion *= Math.fround(0.99) // air drag — f32 precision is critical! pos += motion // position update

The Math.fround(0.99) is crucial. Minecraft uses 32-bit floats internally. If you use a full 64-bit 0.99, the pearl lands in a slightly wrong position. This calculator uses Math.fround to exactly match Minecraft's behavior.

TNT Explosion Impulse

eyePos = pearlPos + (0, PEARL_EYE_HEIGHT, 0) where PEARL_EYE_HEIGHT = 0.25 × f32(0.85) ≈ 0.2125 Δx = eyePos.x - tntPos.x Δy = eyePos.y - tntPos.y Δz = eyePos.z - tntPos.z dist = sqrt(Δx² + Δy² + Δz²) push = (1.0 - dist/8.0) × exposure / dist velocity += push × (Δx, Δy, Δz)

Two TNT groups (Early and Late) fire at perpendicular angles to span the 2D horizontal plane. An Upaccel group fires from below to give the pearl vertical lift.

Why y=127 for First-Time Nether Travel?

🧱 No block pre-placed? Aim at the Nether's bedrock ceiling (y=127). The pearl hits the bedrock naturally — no pre-placed block required. You appear just below the ceiling at your destination.

Normally the cannon shoots the pearl up to y=255 (overworld build limit) where you've pre-placed a block. In the Nether, bedrock at y=127 acts as that natural "ceiling block." This calculator searches for upaccel TNT counts whose peak Y is ≤ the stop height (128), so only valid Nether-ceiling trajectories appear.

Wool Encoding

TNT counts are encoded in a mixed-radix system using colored wool blocks:

Red — Early TNT ÷ 418 (big multiplier)
Orange — (Early TNT mod 418) ÷ 11 (medium multiplier)
Pink — Early TNT mod 11 (small units)
Light Blue — Late TNT ÷ 418
Lime — (Late TNT mod 418) ÷ 11
Cyan — Late TNT mod 11
Blue — Upaccel ÷ 8
Purple — Upaccel mod 8
Yellow — Direction (0–7, +8 if long range)
Purple2 — Angle within direction (0–3)
